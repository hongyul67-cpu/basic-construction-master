# ✏️ 기본 도법 작도 트레이너 — 자와 컴퍼스로 그리기

**기초제도 Ⅲ. 제도의 기본 도법 — 1. 평면 도형 그리기** 단원용 학습·수업 보조 도구입니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

## 왜 만들었나

작도는 칠판에 한 번 그려 주면 끝나 버려서, 학생이 놓치면 되돌릴 수가 없습니다.
이 도구는 8가지 작도를 **단계 버튼으로 몇 번이고 되감을 수 있게** 만들고,
"이 단계에서 **컴퍼스 바늘을 어디에 꽂아야 하나**"를 그림 위에서 직접 눌러 답하게 합니다.

작도의 핵심은 하나입니다 — **눈금으로 재지 않고, 같은 반지름으로 두 번 그려 생긴 교점을 쓴다.**

## 구성

| 모드 | 내용 |
|------|------|
| 📖 **배우기** | 작도 8종을 단계별로. `▶ 자동으로 그리기`로 재생, 마지막에 **왜 그렇게 되는지** 원리 설명 |
| **도전 ①** 컴퍼스 놓기 | 그림 위의 점을 직접 눌러 **컴퍼스 바늘 자리**를 고르기 |
| **도전 ②** 다음 단계 | 여기까지 그린 그림을 보고 **바로 다음에 할 일** 고르기 |
| **도전 ③** 무슨 작도? | 완성된 그림을 보고 **어떤 작도인지** 고르기 |
| 🎯 **종합시험** | 그림 문제 + 원리 문제를 섞어 10문항 출제 후 **결과 제출** |

> 배우기에서 작도를 끝까지 넘길 때마다 그 작도에 ✓ 가 남습니다(localStorage). 8개를 다 보면 탭에도 ✓.

## 수록 작도 8종

| 작도 | 핵심 원리 |
|------|----------|
| 선분의 수직 2등분 | 두 끝점에서 **같은 반지름** → 교점은 양 끝에서 등거리 (반지름은 **절반보다 크게**) |
| 직선 밖 점에서 수선 | 같은 원리를 두 번 써서 직각을 만든다 |
| 선분의 n등분 (5등분) | **평행선 비례** — 보조선의 각도·간격은 아무거나 |
| 각의 2등분 | 두 변 위 등거리 점에서 같은 반지름 → 삼각형 합동 |
| 직각의 3등분 | **반지름과 같은 현 = 중심각 60°** (임의각 3등분은 불가, 직각은 가능) |
| 원에 내접하는 정육각형 | **한 변 = 반지름** (육각 볼트머리 작도) |
| 세 점을 지나는 원 | 두 수직 이등분선의 교점 = 세 점에서 등거리 = 중심 |
| 타원 (동심원법) | 큰 원 등분점의 **세로선** × 작은 원 등분점의 **가로선** |

> 8종 모두 좌표를 원·직선의 실제 교점 계산으로 만들었고, **25개 기하 조건을 자동 검산**했습니다
> (수직 여부, 등분 간격, 3등분 각도 60°/30°, 한 변 = 반지름, 타원 방정식 등).

## 수업에서 쓰는 법

- **수업 자료**: 작도를 고르고 `▶ 자동으로 그리기`. 설명하다 놓친 학생이 있으면 `← 이전 단계`로 되감으면 됩니다.
- **형성평가(제출)**: 주소 뒤에 `?rc=<Apps Script URL>` 을 붙여 배포하면, 종합시험 종료 시 학생이 **반·번호**를 넣어 제출하고 결과가 구글 시트에 모입니다.
  ```
  .../basic-construction-master/?rc=https://script.google.com/macros/s/.../exec
  ```
- **연결**: 여기서 배운 수직 이등분·등분은 뒤의 **투상도·전개도** 작도에 그대로 쓰입니다.
